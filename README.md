# Vrinda-Store-Sales-Performance-Dashboard
Interactive Excel dashboard providing insights into sales trends, customer behaviour, order performance, and regional sales.

Project Overview

Designed an interactive Excel dashboard to analyze Vrinda Store's annual sales performance and convert raw sales data into meaningful business insights. The dashboard enables users to explore sales performance dynamically using filters and visualizations.

Key Features
Built an interactive dashboard using Pivot Tables, Pivot Charts, and Slicers.
Analyzed monthly Orders vs Sales trends to identify seasonal patterns.
Evaluated sales contribution by gender and customer age groups.
Identified the Top 5 States contributing to overall sales.
Analyzed order status, including Delivered, Cancelled, Returned, and Refunded orders.
Compared sales performance across different online sales channels such as Amazon, Flipkart, Myntra, and Ajio.
Added interactive slicers for Month, Category, and Channel to enable dynamic report exploration.
